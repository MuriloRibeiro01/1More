Como transformar o Design System 1More (Garagem 69) em código no app React Native + Expo. O theme.ts
abaixo é gerado de tokens.json : quando um token mudar, regenere o arquivo em vez de editar valores soltos.

FONTES
Instale @expo-google-fonts/racing-sans-one , @expo-google-fonts/barlow , @expo-google-fonts/barlow-
condensed  e @expo-google-fonts/ibm-plex-mono  (ou copie os .ttf  do Google Fonts para assets/fonts  no
CLI). Carregue só os pesos usados:
import { useFonts } from 'expo-font';
import { RacingSansOne_400Regular } from '@expo-google-fonts/racing-sans-one';
import { Barlow_400Regular, Barlow_500Medium, Barlow_600SemiBold, Barlow_700Bold } from '@expo-google-
fonts/barlow';
import { BarlowCondensed_700Bold, BarlowCondensed_800ExtraBold } from '@expo-google-fonts/barlow-
condensed';
import { IBMPlexMono_500Medium, IBMPlexMono_600SemiBold } from '@expo-google-fonts/ibm-plex-mono';
export function useOneMoreFonts() {
  return useFonts({ RacingSansOne_400Regular, Barlow_400Regular, Barlow_500Medium, Barlow_600SemiBold, 
Barlow_700Bold,
    BarlowCondensed_700Bold, BarlowCondensed_800ExtraBold, IBMPlexMono_500Medium, 
IBMPlexMono_600SemiBold });
}
No RN, peso vem do fontFamily  (cada peso é uma família): nunca combine fontWeight  com essas fontes.

WEB REACT NATIVE
Sublinhado duplo do título Dois View s de 1px em ink  separados por 2px.
Anel de foco borderWidth: 2 , borderColor: focus  no estado focado (teclado externo e leitor de
tela).
Alvo de 48px minHeight: size.sizeTouch  ou hitSlop  até 48. Vale para Chip  (40 visível +
hitSlop  4).
Toque Pressable  com fundo paperSunk  em pressed , sem ripple colorido
( android_ripple={{ color: colors[theme].paperSunk }} ).
Carimbo de PR transform: [{ rotate: '-6deg' }] , borda 2px + um View  externo com borda 1px a
2px de distância.
Ícones react-native-svg  com os paths de assets/Icons/  (ou ICON_PATHS  do bundle),
strokeLinecap="square" , strokeLinejoin="miter" .
COMPORTAMENTO OBRIGATÓRIO NA TELA DE TREINO
Concluir série grava no SQLite em transação antes de mudar o visual (RNF-02); a UI responde em < 100 ms
(RNF-04).
expo-haptics  ( impactAsync(Light) ) ao concluir série; notificationAsync(Success)  ao bater PR.
expo-keep-awake  ativo enquanto houver treino ativo (RF-72).
Timer de descanso guarda o timestamp de término e agenda notificação local — não conta com
setInterval  em segundo plano (RNF-13).
Teclado: keyboardType="decimal-pad"  para carga, "number-pad"  para reps; selectTextOnFocus .
Leitor de tela: accessibilityRole="checkbox"  + accessibilityState={{ checked }}  no SetCheck ; o
rótulo diz a série ("Concluir série 2, 80 quilos, 9 repetições").

TabBar Navegação Navegação principal fixa, 4 abas e nada mais: Treinar · Histórico ·

SectionHeader Navegação Rótulo de seção em caixa alta com uma linha fina até a borda, e ação

WeekTally Progresso A semana como página de agenda: um X de caneta em cada dia treinado,
hoje com borda de tinta, contagem contra a meta e a sequência em

StatGrid Progresso Grade 2×N de números grandes em mono com rótulo em caixa alta — o

HistoryRow Histórico Linha do histórico: data na margem (dia em mono + mês), nome do treino,
resumo em mono e carimbo de PR quando houver (RF-41).
CalendarMonth Histórico Mês em grade, semana começando na segunda (RN-24).
ProgressChart Progresso Gráfico de linha em papel milimetrado: grade fina de pauta, linha de tinta

ListRow Navegação Linha genérica de 56px para Perfil e Configurações: ícone, rótulo (+

Sheet Feedback Folha que sobe de baixo para escolhas rápidas e confirmações: opções
